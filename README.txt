Тести з орієнтування (початковий рівень)
========================================

Статичний сайт: звичайні HTML, CSS і JavaScript.
Сервер збирати не треба. Обліковий запис не потрібен.
Результати зберігаються лише у вашому браузері.

Після розпакування архіву з’явиться одна тека.
Файл index.html лежить одразу в ній, поруч із css, js і цим файлом.

Як опублікувати на Cloudflare Pages
------------------------------------
1. Розпакуйте архів.
2. Відкрийте Cloudflare: Workers and Pages → Create → Pages → Upload assets.
3. Завантажте вміст теки, а не саму теку як зайвий рівень.
   У корені проєкту має бути index.html.
4. Назву проєкту вкажіть точно так: testy-orientuvannia
5. Безкоштовна адреса після публікації:
   https://testy-orientuvannia.pages.dev

Власне ім’я testy-orientuvannia.com.ua можна прив’язати пізніше.
Це необов’язковий крок: у Pages додайте custom domain і налаштуйте
DNS у реєстратора домену.

Перевірка на своєму комп’ютері
------------------------------
Відкрийте index.html у браузері або в теці сайту виконайте:

  python3 -m http.server

і зайдіть на http://127.0.0.1:8000

Схеми на сайті навчальні й спрощені. Це не фрагменти змагальних карт.
